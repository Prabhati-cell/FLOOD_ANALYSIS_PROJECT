# Climate-Based Flood Risk Analysis and Prediction

This project analyzes India flood inventory data and builds models to predict flood risk. It includes EDA, KPI calculations, model training, explainability, and a Streamlit dashboard.

Contents:
- `data_processing.py` - dataset inspection and preprocessing
- `modeling.py` - feature engineering, model training and evaluation
- `app.py` - Streamlit dashboard
- `requirements.txt` - Python dependencies
- `India_Flood_Inventory_v3.csv` - dataset (provided)

Notes:
- Insights are data-driven and limited by dataset coverage and quality. Predictions are model-based estimates, not official warnings.
